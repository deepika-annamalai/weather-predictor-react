# 🌦️ Weather Predictor

A simple and responsive Weather App built with **React** that allows users to search for the current weather of any city using the WeatherAPI.

👉 https://deepika-weather-predictor.netlify.app/

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature (°C)
- 🌤️ Show current weather condition
- 📍 Display city and region
- ⏰ Show local time
- 💧 Display humidity
- ⌨️ Press **Enter** to search
- 💾 Saves the last searched city using Local Storage
- ❌ Handles invalid city names gracefully
- 🚫 Prevents empty searches

## 🛠️ Built With

- React
- JavaScript (ES6+)
- CSS3
- WeatherAPI
- Local Storage
- Vite

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-github-repository-link>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
